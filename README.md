# Experimental Sound Synthesizer

**Полевой рекордер несуществующих мест.** Вы вводите место и время — «Озеро Тишины, 4:12» — и прибор
настраивается на него: ветер, дождь, гроза, лес или совсем неземной шум собираются из простых волн
и шума — **без готовых записей и сэмплов**.

Стек: обычные HTML, CSS и JavaScript-модули, звук — [Tone.js](https://tonejs.github.io), пейзаж —
[p5.js](https://p5js.org), запуск и сборка — [Bun](https://bun.sh). Без React и без фреймворков.

## Запуск

Нужен Bun 1.2 или новее. Установка на Mac: `brew install oven-sh/bun/bun`
(или `curl -fsSL https://bun.sh/install | bash`).

```bash
bun install      # скачает Tone.js и p5.js в node_modules
bun run dev      # откроется адрес из консоли, обычно http://localhost:3000
bun run build    # готовая сборка в папке dist/
```

В VS Code: откройте папку проекта, терминал `Ctrl + ~`, затем команды выше.
Звук включается пробелом или кнопкой старта в рекордере — браузер не разрешает автозапуск звука без действия пользователя.

## Концепция

**Место и есть интерфейс.** Пейзаж занимает весь экран, а ручки живут внутри него: небо, облако,
горизонт, тропа, погода. Нет панелей с кнопками — вы двигаете сам мир, и звук меняется.
Интерфейс поверх пейзажа тонкий и полупрозрачный, а его цвета подстраиваются под время суток и погоду
места (`src/world/palette.js`).

Природа здесь не воспроизводится, а **собирается** из простых электронных сигналов: розовый шум через
дышащий фильтр становится ветром, высокий синус с блуждающей высотой — свистом, короткий удар мембраны —
каплей. Таких мест на карте нет — их придумывает сам зритель.

**Строка места — это зерно (seed).** Название и время превращаются в число, а из него детерминированно
выводится всё остальное: тип погоды (по словам — «гроза», «лес», «перевал», «планета»), время суток,
положение каждой ручки и узор из 16 наблюдений. Поэтому **одна и та же строка — всегда одно и то же место
и один и тот же звук**, а похожие места звучат похоже, но не одинаково. Ночью звук темнее, просторнее и
медленнее, на рассвете и в сумерки голос B дрожит сильнее.

- Введите место и нажмите **Enter** (или «НАСТРОИТЬ ↵»). Время можно написать цифрами (`4:12`)
  или словами («на рассвете», «в полночь»); если его нет, оно возьмётся из зерна.
- Пять готовых мест — ПЕРЕВАЛ, САД, ГРОЗА, ЛЕС, ПЛАНЕТА — клавиши **1–5**.
- Кнопка **ССЫЛКА** копирует адрес вида `…/?place=Озеро%20Тишины%2C%204%3A12`: откройте его — и прибор
  сразу настроится на то же место. Так местами делятся.
- После настройки всё можно крутить руками: это уже ваша запись с места.
- Рекордер («РЕКОРДЕР · ЭКСПЕДИЦИЯ») пишет исполнение в WAV; файл называется по месту: `Озеро Тишины 04-12 — ESS.wav`.

## Как устроен звук

```
ГОЛОС A · ВОЗДУХ      шум / волна → фильтр (+LFO «порывы»)           → КАНАЛ A ┐
ГОЛОС B · СТИХИЯ      волна + шум → фильтр → дрожь                   → КАНАЛ B ┤
ЧАСТИЦЫ               капля · щелчок · треск · раскат (16 шагов)     → КАНАЛ Ч ┤
                                                                               ▼
КАНАЛ (A, B, Ч — у каждого свой):                            ОБЩИЙ КАНАЛ:
Жар → Марево → Ущелье → Даль → громкость → панорама      яркость → громкость → лимитер
                                   └ уровень → план местности           → выход и запись (WAV)
```

- **Два голоса и частицы** — три независимых источника.
- **У каждого канала своя цепочка эффектов** из четырёх звеньев. Эхо привязано к темпу и у каждого
  канала своё (A — пунктирная восьмая, B — восьмая, Ч — короче), длина реверберации тоже разная.
- **Звук разведён по каналам**: у A, B и частиц своя громкость и панорама (на плане местности это
  расстояние и сторона), затем они сходятся в общий канал.

## Интерфейс

| Где | Что делает |
|---|---|
| Слева сверху · заголовок | Название места крупно, время, погода и текущий шаг. Пока звук не включён, мигает подсказка «ПРОБЕЛ — НАСТРОИТЬСЯ НА МЕСТО» |
| Справа сверху · место | Поле «Куда отправимся?», «НАСТРОИТЬ ↵», пять готовых мест (ПЕРЕВАЛ, САД, ГРОЗА, ЛЕС, ПЛАНЕТА), «ССЫЛКА» — копирует адрес с `?place=` |
| НЕБО · облако | **Голос A · ВОЗДУХ.** Облако тянут мышью: по горизонтали — ВЫСОТА, по вертикали — ПЛОТНОСТЬ. Клик открывает лист наблюдения |
| ГОРИЗОНТ | **Голос B · СТИХИЯ.** Линию горизонта тянут вверх и вниз — это ВЫСОТА свиста. Клик открывает лист наблюдения |
| ТРОПА · внизу | 16 наблюдений частиц: капля, щелчок, треск, раскат. Подсвечивает текущий шаг |
| ПОГОДА · ЦЕПЬ · справа | Цепочка эффектов выбранного канала: ЖАР (drive) → МАРЕВО (модуляция) → УЩЕЛЬЕ (эхо) → ДАЛЬ (реверберация) |
| ПЛАН МЕСТНОСТИ · слева снизу | Микшер: три источника (A, B, частицы) стоят вокруг слушателя. Расстояние — громкость, сторона — панорама |
| ЛИСТ НАБЛЮДЕНИЯ · слева | Выезжающая панель точных настроек голоса A или B: форма волны и ползунки |
| РЕКОРДЕР · справа снизу | Запись (кнопка REC), таймер, старт / стоп / скачать WAV, ТЕМП, ползунки ОБЩИЙ (общая громкость) и СОЛНЦЕ (яркость общего канала) |
| Нижняя строка | Подсказка по клавишам |

Ползунки: перетаскивание, колесо мыши и стрелки клавиатуры; двойной клик возвращает значение по умолчанию.

### Горячие клавиши для живого исполнения

| Клавиша | Действие |
|---|---|
| Пробел | старт / стоп |
| R | начать / закончить запись |
| / | перейти в поле места (Enter — настроить, Esc — выйти из поля) |
| 1 – 5 | места: Ветреный перевал, Дождливый сад, Гроза над полем, Ночной лес, Кристальная планета |
| Q / W / E | цепочка погоды для A / B / частиц |
| A / B | открыть лист наблюдения голоса A / B (работает и на русской раскладке) |
| Esc | закрыть лист наблюдения |

Пока курсор в поле места, горячие клавиши не срабатывают — можно спокойно печатать «Ветер 1».

## Нейминг компонентов

Один принцип на всё: **имя блока = CSS-класс = файл стилей = JS-модуль**. Классы — по БЭМ:
`блок__элемент--модификатор`, состояния — `is-on`, `is-now`, `is-open`, `is-drag`.

| Блок | Разметка | Стили | Логика |
|---|---|---|---|
| Мир (пейзаж на весь экран) | `.world` | `blocks/world.css` | `ui/world.js` (p5) |
| Облако — голос A | `.sky-handle` | `blocks/sky-handle.css` | `ui/sky-handle.js` |
| Горизонт — голос B | `.horizon-handle` | `blocks/horizon-handle.css` | `ui/horizon-handle.js` |
| Заголовок места | `.hud` | `blocks/hud.css` | `ui/hud.js` |
| Место и пресеты | `.place-bar` | `blocks/place-bar.css` | `ui/place-bar.js` (строка → состояние: `state/place.js`) |
| Лист наблюдения | `.sheet` | `blocks/sheet.css` | `ui/sheet.js` |
| Ползунок | `.slider` | `blocks/slider.css` | `ui/slider.js` |
| Форма волны | `.wave-switch` | `blocks/wave-switch.css` | `ui/wave-switch.js` |
| Погода — цепочка эффектов | `.weather-kit` | `blocks/weather-kit.css` | `ui/weather-kit.js` |
| План местности — микшер | `.field-map` | `blocks/field-map.css` | `ui/field-map.js` |
| Тропа — 16 наблюдений | `.trail` | `blocks/trail.css` | `ui/trail.js` |
| Рекордер | `.recorder` | `blocks/recorder.css` | `ui/recorder.js` |
| Нижняя строка клавиш | `.hint-line` | `blocks/hint-line.css` | `ui/hint-line.js` |

Две общие части не относятся к одному блоку:
- `src/world/geometry.js` — **общие координаты**: где летает облако и где ходит горизонт. Пейзаж и ручки
  поверх него берут их отсюда, поэтому то, что вы тянете мышью, совпадает с нарисованным.
- `src/world/palette.js` — **тема времени суток**: цвета неба и земли, а также CSS-переменные интерфейса
  (`--ink`, `--glass`, `--glow` и другие) для места и погоды.

**Каналы** везде называются одинаково: `a` — голос A, `b` — голос B, `p` — частицы, `master` — общий.
Цвет канала один на всё и лежит в `theme.css` (`--ch-a`, `--ch-b`, `--ch-p`, `--ch-master`).

**Параметры** подключаются в разметке атрибутом `data-param` — это путь в состоянии:
`data-param="a.tune"`, `data-param="mix.master"`, `data-param="fx.*.delay"` (звёздочка — канал,
чья цепочка сейчас открыта). Чтобы добавить ползунок, достаточно написать
`<div class="slider" data-param="..." data-label="..."></div>` и подключить его через `mountSlider`.

## Структура проекта

```
index.html                 каркас: по одному элементу на блок
package.json               зависимости и команды Bun
src/
  main.js                  сборка: монтирует блоки, транспорт, запись, горячие клавиши, тема времени суток
  audio/engine.js          звуковые цепочки на Tone.js
  audio/wav.js             экспорт записи в WAV
  state/store.js           хранилище состояния и пути параметров
  state/place.js           строка места → зерно → полное состояние, готовые места (PRESETS)
  state/scenes.js          заготовки по типам погоды (ARCHETYPES), волны, дорожки частиц
  world/geometry.js        общие координаты облака и горизонта
  world/palette.js         цвета неба и земли, тема интерфейса по времени суток
  ui/*.js                  компоненты интерфейса (по одному на блок)
  styles/
    index.css              подключает всё по порядку
    fonts.css              ← шрифты
    theme.css              ← цвета каналов и тема по умолчанию
    base.css               общие правила
    blocks/*.css           стили блоков (по одному на блок)
```

## Как поменять шрифт

Поменяйте ссылку Google Fonts в `index.html` и имена в `src/styles/fonts.css`
(`--font-display` — название места, `--font-ui`, `--font-mono`). Шрифт нужен с кириллицей.
Для показа без интернета положите `.woff2` в `src/styles/fonts/` и раскомментируйте `@font-face`
в `fonts.css`.

## Как добавить своё готовое место

В `src/state/place.js` добавьте объект `{ query, label }` в массив `PRESETS`: `query` — строка места
(она же зерно), `label` — подпись на кнопке в шапке. Кнопка появится сама, клавиша — следующая по номеру
(цифры работают до 9). Чтобы научить прибор новому типу погоды, добавьте заготовку в `ARCHETYPES`
(`src/state/scenes.js`) и ключевые слова в `WEATHER_WORDS` (`place.js`).

## Загрузка на GitHub через GitHub Desktop

1. **File → Add Local Repository…** → выберите папку проекта. Если GitHub Desktop предложит
   «create a repository» — согласитесь.
2. Слева внизу напишите сообщение коммита и нажмите **Commit to main**.
3. **Publish repository** → снимите галочку «Keep this code private», если ссылка нужна для просмотра.
4. Ссылка на репозиторий: **Repository → View on GitHub**.

Папки `node_modules/` и `dist/` в репозиторий не попадают (см. `.gitignore`), а файл `bun.lock`,
который появится после `bun install`, коммитить нужно — он фиксирует версии библиотек.
